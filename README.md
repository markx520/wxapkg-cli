# wxapkg-cli

一款轻量、无头（Headless）且基于纯内存流处理的微信小程序包离线解析工具。

## 项目亮点

1. **纯内存流式解密**：解密、格式转换与索引解析全程在内存中流式执行，不落地任何解密中间临时文件。
2. **零图形依赖**：彻底剥离桌面 UI 框架，支持纯终端交互与自动化流水线调用。
3. **安全免注入**：仅通过只读文件拓扑感知与前台窗口枚举工作，不包含任何进程挂钩与动态注入行为。

## 快速安装

```bash
git clone https://github.com/<your_username>/wxapkg-cli.git
cd wxapkg-cli
pip install -r requirements.txt
```

## 常用命令

1. 枚举当前打开的前台小程序窗口：
   ```bash
   python main.py ps
   ```

2. 扫描最近活跃的小程序包：
   ```bash
   python main.py scan -m 1440
   ```

3. 纯内存流解包：
   ```bash
   python main.py unpack <__APP__.wxapkg路径> -i <小程序AppID> -o <输出目录>
   ```
   如果文件路径中包含小程序的 AppID（例如 `wx1234567890abcdef`），工具将自动识别，无需手动指定 `-i` 参数。
